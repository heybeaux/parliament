Better reasoning, not better models.

The Problem

AI agents are impulsive.

They get a task. They execute. No pause. No deliberation. No "should I actually do this?"

🔲

Blind spots

The model doesn't know what it doesn't know. It can't see its own gaps.

🔄

No productive self-debate

A single model can't argue with itself. Chain-of-thought is monologue, not dialogue.

📏

Unexamined tradeoffs

It won't surface tradeoffs it wasn't prompted to consider. You get what you ask for — nothing more.

🧠

No institutional memory

Every decision starts cold. Past mistakes, past wins — all forgotten next time.

The Solution

You don't need a smarter model.

You need a smarter process.

Parliament puts multiple AI agents with different cognitive postures in a room to debate a topic on a shared blackboard. They argue, they challenge, they synthesize — until they reach consensus, surface an irreconcilable split, or hit a timeout.

Neurotypes

Thirteen specialized deliberation postures — Proposer, Skeptic, Empiricist, Historian, Forecaster, Pragmatist, Lateralist, and more. Each brings a different lens to the same problem.

Topology Presets

Compose neurotypes into reusable deliberation shapes. jury for avoiding framing bias. long-view for long-term consequences. reframe for stuck thinking.

Echo Detection

The Sentry monitors for agreement loops. The Opinion Shift Index tracks whether agents are actually moving or just repeating themselves. Premature consensus gets disrupted by the Red Agent.

Local-First

Runs on oMLX with local models. Privacy-preserving, no API keys needed. Multi-provider support for Ollama, LM Studio, and OpenAI-compatible backends.

The Integration Story

  1. Query lands: "Should we change our architecture?"
  2. ACR resolves what context matters — specs, capabilities, constraints
  3. Engram pulls past decisions, known issues, what's been tried
  4. Parliament deliberates with that context loaded
  5. Decision is recorded back to Engram

Real Output

See the deliberation.

An actual Parliament run on a real architectural decision. Not mock data — a real deliberation with real tradeoffs.

Topic: Should Endeavour integrate Parliament as a self-deliberation layer? 5 rounds · Jury preset · Residue: 1.0 · Irreconcilable split
Proposer

Endeavour should implement Parliament as a conditional, triggered layer rather than a default pipeline. Given the compute constraints of Apple Silicon, a permanent multi-agent overhead would degrade performance for routine tasks. However, the synergy between Parliament and Engram shared memory pools creates a unique opportunity for high-stakes meta-reasoning.

Skeptic

The Proposer assumes the Opinion Shift Index reliably detects internal stagnation. This is an unsupported leap. Running specialized agents alongside Qwen 35B on Apple Silicon risks thermal throttling regardless of frequency. Without distinct model architectures, cognitive postures may converge rather than diverge.

Red Agent

You are not building a parliament; you are building a choir of identical voices arguing over bandwidth until the chip throttles. The real risk is not latency but hallucination amplification through redundant context loading. If the underlying weights remain static, the diversity is just variance in sampling, not epistemic growth.

Skeptic

RedAgent commits a logical error by asserting identical model weights preclude cognitive divergence, ignoring stochastic sampling parameters like temperature that ensure output variance even with shared priors. The debate lacks empirical grounding — no benchmarks quantify attention budget dilution or thermal throttling thresholds.

Result: Irreconcilable split. Parliament correctly identified that this question cannot be resolved by reasoning alone — it needs empirical data. The debate surfaced considerations a single-model pipeline would have missed entirely.
