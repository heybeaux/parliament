# Parliament

Reasoning faculty in the heybeaux stack. A synthetic discourse engine that runs multi-round multi-model deliberation with managed AI misalignment (red agent, sentry, synthesizer) to produce resilient reasoning under uncertainty. Lineups can be cooperative (consensus-seeking) or adversarial (critique-driven). Results persist to a local SQLite DB; the HTTP API is a view over it.

**Provides:** reasoning-faculty, deliberation-engine, synthesis
**Repo:** https://github.com/heybeaux/parliament
**Relates to:** the reasoning faculty in Sonder; Inos uses Parliament for the `deliberation` node type natively
